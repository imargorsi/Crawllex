## 6. Access & Governance

### Two Layers Of Authority

| Layer | Who | What They Control |
|---|---|---|
| Platform | Super Admin | Users, role templates, project approval and lifecycle |
| Project | Owner, custom roles, members | What that person can do inside one selected project |

### Default Project Roles

| Role | Typical Intent |
|---|---|
| Project Owner | Full operational access for that project, including inviting and removing members |
| Project User | View-oriented access (for example analytics, activities, and leads; no invite/remove by default) |
| Custom Roles | Templates created by Super Admin with a chosen permission mix (for example “SEO Lead” or “Client Viewer”) |
