# 1. What Is Crawllex

Crawllex is a multi-client SEO operations platform. Each client website is its own project workspace. An agency runs many clients in one place, controls who sees what per project, and presents a clean client-ready view of performance, delivery, and leads — without sharing Google logins or internal admin tools with clients.

### Core Capabilities

| Capability | What it does |
|---|---|
| Secure Accounts | Registration, login, email verification, password recovery, and profile management |
| Project Workspaces | One isolated workspace per client / website |
| Project Onboarding | Guided setup for business info, services, SEO goals, locations, and competitors |
| Project Lifecycle | Approve, reject, pause, or reactivate projects |
| Roles & Permissions | Reusable project role templates and a permission matrix |
| Team Collaboration | Invite members to a project with project-scoped access |
| Dashboard Overview | Project home with summary widgets and engagement health |
| Performance Analytics | Search Console + GA4 KPIs, trends, queries, pages, demographics, and export |
| SEO Activities | Log and export blogs, backlinks, and technical work |
| Lead Tracking | Capture and manage inquiries per project (CSV import, then WordPress automation) |
| Google Integrations | Link GSC site and GA4 property per project; clients only consume the data |
| Settings & Personalization | Profile, password, theme packs, and font packs |
