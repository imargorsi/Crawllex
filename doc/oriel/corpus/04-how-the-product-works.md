## 5. How The Product Works

1. Sign up and log in.
2. Create your first project (onboarding). Status: Pending Approval.
3. A platform operator approves the project. Status: Active.
4. A team member links Google Search Console and GA4 in Settings → Integrations.
5. The project owner invites team members.
6. Team members select the project in the sidebar and use:
   - Dashboard Overview
   - Analytics (read performance data)
   - SEO Activities (log and export delivery work)
   - Leads (CSV import and WordPress capture)

### Project Lifecycle

| Status | Meaning |
|---|---|
| Pending | Submitted; waiting for operator review. Owners can still edit the profile and invite members. Operational modules stay limited until active. |
| Active | Approved and live. Members get their role-based module access. |
| Inactive | Paused by an operator. Membership remains; operational access is restricted. |
| Rejected | Closed — the project is not available for operational work. |

Operators may also create a project as Active immediately and assign an owner.
