# Module 6 — Project Access Control

### Rules

Project Owner can access owned projects.

Project Members can only access assigned projects.

Admin bypasses all project restrictions.

Users can belong to multiple projects.

Every project-based query must filter by project_id.

Prevent cross-project data access.
