Phase 5. Findings and gaps

Strong for Local SEO. The GBP profile, reviews and Maps rank are populated and immediately useful: review gaps, owner replies and city-level rank gaps can be shown to clients per keyword.
Weak for this client. Labs organic data and LLM citations are empty or generic. The value case depends on the client's footprint, so the demo needs a site that ranks and is cited.
  • Fee floors: LLM Mentions costs at least $0.10 per call even with 0 results. Plan the call count, not only the rows.
  • Live vs Standard: nightly jobs must use Standard. Live Maps is $0.002 vs $0.0006 Standard.
  • Engineering gap: ChatGPT-platform LLM search rejected the location field (error 40000). Not charged. Fix before the full test.
  • Plan document: section 5.7 needs the corrections above. GBP reviews frequency (weekly vs monthly) and "manual refresh not charged" wording also need fixing.
