# Crawllex report renderer

Turns one HTML report into one A4 PDF. Standalone Node service. It does not import from the Crawllex app,
so it runs on logibox now and can move to any other server later.

## Contract

| Method | Path | Auth | Body | Response |
|--------|------|------|------|----------|
| GET | `/health` | none | — | `200 {"ok":true}` |
| POST | `/render` | `Authorization: Bearer <REPORT_RENDERER_TOKEN>` | `text/html`, max 5 MB | `200 application/pdf` |

Errors: `401` bad token, `413` too large, `415` wrong content type, `500` render failed (no details leaked).

## Requirements

- Node.js 20 or newer
- Chromium or Google Chrome (set `CHROME_PATH`). On Ubuntu: `sudo apt install chromium` (or the distro package)
- Fonts with Latin and Arabic glyphs (`fonts-liberation`, `fonts-noto-core` recommended)

## Run

```bash
cd services/report-renderer
npm ci
REPORT_RENDERER_TOKEN='<long random secret>' \
CHROME_PATH=/usr/bin/chromium \
HOST=127.0.0.1 PORT=8788 \
node server.mjs
```

Quick check:

```bash
curl -s http://127.0.0.1:8788/health
curl -s -o test.pdf -X POST http://127.0.0.1:8788/render \
  -H "Authorization: Bearer $REPORT_RENDERER_TOKEN" \
  -H "Content-Type: text/html; charset=utf-8" \
  --data-binary @report.html
```

## Connect the app

Set in the Crawllex environment (`.env.local` for dev, Hostinger env for prod):

```
REPORT_RENDERER_URL=http://127.0.0.1:8788
REPORT_RENDERER_TOKEN=<same secret>
```

If the app runs on another machine, expose the renderer only through a private network (Tailscale, VPN)
or a tunnel with access control. Do not publish port 8788.

## logibox (deployed 2026-11-02)

- Runs as a systemd **user** unit on logibox (`~/.config/systemd/user/report-renderer.service`, linger on).
  Code in `~/apps/report-renderer`; env file `.env` (mode 600) with the token, `CHROME_PATH=/usr/bin/google-chrome-stable`,
  `HOST=0.0.0.0`, `PORT=8788`. UFW allows 8788 only on tailscale0 (LAN is blocked). Node 26.8.1 via mise.
  Dev app URL: `http://100.90.184.0:8788`.
- Changes are logged in the logibox dossier (`/mnt/projects/logibox-dossier`, SETUP_LOG.md) and published with its `tools/publish.sh`.
- No secrets in git. The token lives only in the environment file on each host.

## Security notes

- Every request must carry the Bearer token. The comparison is constant-time.
- The page can load no network resources (all requests are aborted except `data:`). Reports must be self-contained.
- Concurrency is capped (`MAX_CONCURRENT_PAGES`, default 2). Each render has a timeout (`RENDER_TIMEOUT_MS`).
- Chromium runs with `--no-sandbox`, which is needed for many server setups. Only feed it HTML generated by Crawllex.
